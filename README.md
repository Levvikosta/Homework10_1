### Фикстуры для тестирования

- **Фикстура для тестирования `get_mask_card_number`**:
  - Проверяет корректность маскирования номера карты.
  - Тестирует различные сценарии, включая корректные и некорректные номера.

- **Фикстура для тестирования `get_mask_account`**:
  - Проверяет корректность маскирования номера счета.
  - Тестирует различные сценарии, включая короткие номера и пустые строки.

- **Фикстура для генерации входных данных**:
  - Проверяет корректность формата даты.
  - Тестирует различные форматы, включая корректные и некорректные.

В этом дз добавлен новый модуль generators, который позволяет генерировать последовательности номеров карт в заданном диапазоне. Также расширены тесты и добавлены примеры использования функций из следующих модулей:

card_number_generator(start, end) — генератор номеров карт в диапазоне
filter_by_currency(transactions, currency) — фильтрация транзакций по валюте
transaction_descriptions(transactions) — генерация описаний транзакций


## Генераторы (модуль generators)

### filter_by_currency(transactions, currency)
Фильтрует транзакции по валюте.
### transaction_descriptions(transactions)
Возвращает описания транзакций.
### card_number_generator(start, end)
Генерирует номера карт в заданном диапазоне.
